# Анализ рынка вина на Python

Учебный проект программы «Аналитик данных (Python)».
Задача: помочь интернет-магазину понять, что определяет цену и популярность вина.

## Данные
- Файл с данными включён в репозиторий: `wine_reviews.csv` (20 000 записей × 10 признаков, 31 страна)
- Источник: публичный датасет оценок вина (Kaggle)
- Для воспроизведения анализа откройте ноутбук — данные лежат рядом с ним

## Что сделано
- Полный цикл: очистка (20 000 → 14 661 строки) → новые признаки → EDA → гипотезы → моделирование
- 97% рынка — вина до $100, медианная цена — $26
- Рейтинг объясняет 26% дисперсии цены (R² = 0.26): «дорогое» ≠ «высоко оценённое»
- Гипотеза 1: цены США и Франции различаются — подтверждена двумя тестами (Уэлча и Манна-Уитни, p < 0.05)
- Гипотеза 2: популярные и непопулярные вина различаются по цене и рейтингу — подтверждена
